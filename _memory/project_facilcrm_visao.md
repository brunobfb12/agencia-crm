**Domínio:** ocrmfacil.com.br (facilcrm.com.br pertence a outra empresa — não usar)

**Proposta de valor:** O cliente (empresa) não precisa fazer quase nada — o Claude (IA) faz o trabalho pesado automaticamente via WhatsApp.

**Funcionalidades planejadas para o CRM:**
- Atendimento automático via WhatsApp (responder, qualificar leads)
- Registro automático de dados do cliente no CRM (nome, telefone, interesse)
- Agendamento automático de follow-up
- Contato automático de aniversário
- Histórico completo de conversas salvo para referência futura
- Histórico de compras por cliente
- Puxar assunto com base no histórico (ex: "da última vez você comprou X, temos novidade")
- Qualificação de leads automática com score

**Why:** A diferenciação do produto é justamente a automação — o dono da empresa só monitora resultados, a IA faz o relacionamento.
**How to apply:** Toda decisão de desenvolvimento deve priorizar o que reduz o trabalho manual do cliente. Features que exigem ação humana são menos prioritárias.
